 ❤️ Cardioso

Cardioso is a machine learning project for heart disease prediction using the UCI Heart Disease dataset.

The project compares two classification models:

Random Forest
XGBoost

Features

- Data cleaning and preprocessing
- Missing-value handling
- Categorical feature encoding
- Random Forest and XGBoost training
- Model evaluation
- Terminal-based prediction with `predict.py`
- Interactive Streamlit web application

Tech Stack

Python • Pandas • NumPy • Scikit-learn • XGBoost • Joblib • Streamlit
